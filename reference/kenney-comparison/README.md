# kenney-comparison — Kenney 素材の採否審査記録（恒久保存）

「ぴよぴよランド」の画風正典 **シールポップ**（太い白フチ・濃いこげ茶アウトライン・
ビビッド配色・大きな瞳と頬）に対し、ハイブリッド方針の一環で **Kenney の無料素材**を
採用候補として視覚審査した記録。判定日 **2026-07-18**。

## 結論

**Kenney 採用 = 0 件。distinct 65 モチーフすべて自作 SVG（custom）。**

ダウンロード済みの Kenney サンプル群は、シールポップの 4 要件
（①太い白フチ ②濃いアウトライン ③ビビッド彩度 ④かわいい顔つき）を
**1 つも満たさない**。全候補で自作 SVG が明確に上回り、混ぜると世界観の
コヒーレンス（無表情・無フチ・くすみ色が白フチかわいい群から浮く）を壊すため、
「迷ったら custom／画風調和の見込みがある良候補のみ Kenney」に照らして
**該当ゼロ**が正しい帰結。以後この判断を再検討しないための証跡として保存する。

## 補足

- Kenney には「白フチ焼き込み＋かわいい顔」系のパックが存在しないため、
  別パックを追加ダウンロードしても結果は変わらないと判断し、追加取得は見送り。
- 審査に使った Kenney サンプル本体（`reference/kenney-samples/`）は `.gitignore` 済み
  （再ダウンロード可能な第三者素材のためリポジトリには含めない）。本ディレクトリの
  スクショ・判定表が採否の証跡を担う。
