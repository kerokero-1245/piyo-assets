# BGM レンダリング検証

オルゴール風BGM共有エンジン（`engine.js` / `engine.ts`）と4曲（`songs.js` / `songs.ts`）の検証結果。

- 手法: Playwright（システムChrome, channel:chrome, headless）ページ内で `PiyoBgm.renderSong()` を実行し、
  各曲を **2ループ分** `OfflineAudioContext`（mono / 44100Hz）でレンダリング → PCM(Float32)を取得 →
  ページ内(JS)で数値化。試聴WAVは **1ループ+3秒余韻** を別レンダリングし16bit PCM化 → `afconvert` で m4a 変換。
- 交差検証: 生成した WAV を Python(numpy) で再解析し、ピーク/RMS が一致・全サンプル finite（NaN/Inf無し）を確認。
- サンプルレート: 44100 Hz、mono。

## 1. 曲サマリと数値（2ループ・レンダリング）

| 曲 | キー / テンポ | 小節 / ループ長 | ノート数 | ピーク | RMS |
|----|----|----|----|----|----|
| land（街） | C メジャーペンタ / 66 BPM | 16 / 58.18s | 66 | **-17.46 dBFS** | -37.53 dB |
| meiro | G メジャーペンタ / 84 BPM | 16 / 45.71s | 104 | **-18.43 dBFS** | -37.44 dB |
| sansu | F メジャーペンタ / 76 BPM | 16 / 50.53s | 96 | **-18.37 dBFS** | -37.29 dB |
| kotoba | D メジャーペンタ / 92 BPM | 16 / 41.74s | 130 | **-19.28 dBFS** | -37.86 dB |

（ループ長 = 16小節×4拍÷BPM。BGMなので1ループが約42〜58秒と長く、反復感が出にくい。）

## 2. 合格判定

### ピーク < -3dBFS（クリッピングなし）
全曲 **-17.46 〜 -19.28 dBFS**。上限 -3dBFS に対し 14dB 以上の余裕。**合格**。
（控えめBGMの設計どおり。マスターゲイン 0.10 × 曲別 mix。）

### RMS が4曲でほぼ揃う（±2dB以内）
RMS は **-37.29 〜 -37.86 dB**。**最大差 0.58 dB**（許容 ±2dB=幅4dB に対し十分小さい）。**合格**。
音数の多い曲ほど `mix` を下げて（land 1.00 / sansu 0.95 / meiro 0.92 / kotoba 0.86）体感音量を揃えた。

### ループ境界の連続性（クリック無し）
2ループ連続レンダリングの境界（t=ループ長）±10ms の「隣接サンプル差分」を計測。
本エンジンは曲を止めて鳴らし直さず、絶対時刻に予約し続けるため境界は原理的に連続。数値でも
**境界の最大ステップ ＜ 曲全体の最大ステップ** となり、境界に異常な跳ね（クリック）は無い。**合格**。

| 曲 | 境界の最大ステップ | 境界のRMSステップ | （参照）全体の最大ステップ |
|----|----|----|----|
| land | 0.00885 | 0.00257 | 0.01661 |
| meiro | 0.01259 | 0.00347 | 0.02123 |
| sansu | 0.01125 | 0.00320 | 0.02016 |
| kotoba | 0.01135 | 0.00345 | 0.01536 |

境界ステップはいずれも通常の音の立ち上がり（全体最大）より小さく、不連続なし。

### スコア整合（発音数＝スコアのノート数）
レンダラが予約した発音数（/1ループ）＝ スコアのノート数。**全曲一致**。**合格**。

| 曲 | レンダリング発音数 | スコアのノート数 | 一致 |
|----|----|----|----|
| land | 66 | 66 | ✓ |
| meiro | 104 | 104 | ✓ |
| sansu | 96 | 96 | ✓ |
| kotoba | 130 | 130 | ✓ |

### 実ブラウザ（リアルタイム側コードパス）で数秒再生・エラーゼロ
実 `AudioContext` で `createEngine()` → `startBgm()` → `duckBgm()`/`unduckBgm()` → `stopBgm()` を各曲実行。

- 4曲すべて `ctx.state === "running"`、`currentTime` が約1.2〜1.4秒進行（実再生を確認）。
- `pageerror` / `console.error` は **0件**。
- no-op 安全性: `AudioContext` を隠した状態で `createEngine()` と全API呼び出し → `supported:false`、
  **例外・クラッシュなし**（無害な no-op）。

## 3. 総合

全項目 **合格**。ピーク余裕14dB以上・RMS差0.58dB・境界連続・発音数一致・実再生エラーゼロ・no-op安全。
